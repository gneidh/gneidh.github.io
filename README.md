# Guido Neidhöfer — academic website

Live website: https://gneidh.github.io/

A static website served by GitHub Pages from the main branch. No build or package installation is required.

## Pages

index.html: homepage and professional profiles.
about.html: introduction, academic background, affiliations and portraits.
research.html: themes, working papers, interviews and policy contributions.
publications.html: numbered APA references, abstracts or study summaries, and citation copying.
cv.html: CV download and PDF preview.
contact.html: affiliations, contact details and maps.

style.css contains shared responsive styling. site.js handles citation copying. Original images and PDF downloads are in assets/.

## Content conventions

British English is used for website prose; publication titles retain their published spelling. Journal names and volumes are italicized. Publication numbering is preserved, newest additions at the top. Each entry has one DOI link, an expandable abstract or clearly labelled study summary, and a copy-citation button.

The downloadable CV is the existing 2026 PDF prepared on 30 July 2026. Its file has not been revised during this website redesign.
